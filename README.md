# 부스 체크

동인 행사 부스를 미리 정리하고, 당일 선입금 수령·현장 구매를 체크하는 웹앱입니다.

- 파일 하나(`index.html`)로 돌아가요. 서버 없이 GitHub Pages로 배포할 수 있어요.
- 로그인하지 않으면 데이터는 각자 브라우저(localStorage)에만 저장돼요.
- `firebase-config.js`를 채우면 **Google 로그인(기기 간 동기화)**과 **실시간 공유(구독·공동 편집)**가 켜져요.

## 레포에 올릴 파일

```
index.html              앱 본체
firebase-config.js      Firebase 설정값 (직접 채움, 앱을 업데이트해도 이 파일은 그대로 두기)
firestore.rules         Firestore 보안 규칙 (Firebase 콘솔에 붙여 넣는 용도)
sw.js                   오프라인용 (인터넷이 끊겨도 앱이 열리게 해 줌)
manifest.webmanifest    홈 화면 설치 정보
icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png   앱 아이콘
CNAME                   커스텀 도메인을 쓸 때만
```

## 홈 화면 설치 · 오프라인

- 안드로이드 크롬: 설정(톱니바퀴) → ‘앱 설치’ 카드의 **홈 화면에 설치** 버튼, 또는 브라우저 메뉴 → 앱 설치.
- 아이폰 사파리: 공유 버튼 → **홈 화면에 추가**.
- 한 번 열어 두면 그 뒤로는 인터넷이 끊겨도 앱이 열려요. 새 버전은 인터넷이 될 때 열면 자동으로 받아요.

## Firebase 설정 (처음 한 번)

메뉴 이름은 Firebase 콘솔 화면이 바뀌면서 조금 다를 수 있어요.

1. **프로젝트 만들기**: https://console.firebase.google.com 에서 새 프로젝트를 만들어요. Google 애널리틱스는 꺼도 돼요.
2. **웹 앱 등록**: 프로젝트 개요에서 웹 아이콘(`</>`)을 눌러 앱을 등록하면 `firebaseConfig = { apiKey: ..., ... }`가 나와요. 그 값을 `firebase-config.js`에 옮겨 적어요.
3. **Google 로그인 켜기**: Authentication → 시작하기 → 로그인 방법(Sign-in method) → Google → 사용 설정 → 저장.
4. **승인된 도메인 추가**: Authentication → 설정 → 승인된 도메인 → `내아이디.github.io` 추가. 커스텀 도메인을 쓰면 그 도메인도 추가해요.
5. **Firestore 만들기**: Firestore Database → 데이터베이스 만들기 → 위치는 `asia-northeast3 (서울)` 추천(나중에 못 바꿈) → 프로덕션 모드로 시작.
6. **보안 규칙 붙여 넣기**: Firestore → 규칙 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 게시해요.

무료(Spark) 요금제로 충분해요. 이미지는 링크로만 저장해서 Cloud Storage(카드 등록 필요)는 쓰지 않아요.

## 실시간 공유 방식

| 코드 | 받은 사람이 할 수 있는 것 |
|---|---|
| `BCL-XXXXXXXX` (구독 코드·링크) | 원본이 바뀌면 자동 업데이트. 부스·작가 정보, 태그·부스 메모, 무료 배포 물품은 읽기 전용, 나머지 구매 리스트·체크·지인·내 메모는 각자 것 |
| `BCE-XXXXXXXX-…` (편집 코드·링크) | 로그인 후 공동 편집자로 참여. 고친 내용이 모두에게 반영 |

- 공유되는 것: 행사 정보·일정·구역·상품 종류·배치도·부스·태그·부스 메모·작가·인포 이미지 링크·선입금·수요조사 기간과 폼 링크·무료 배포 물품(이름·종류·샘플).
- 공유 안 되는 것: 무료 배포를 뺀 구매 리스트(물품·가격), 모든 물품의 체크·수량, 지인, 작가 메모, 구독자의 ‘내 메모’.
- 원본에서 부스를 지워도, 구독자가 물품·메모를 남긴 부스는 그 사람의 부스로 남아요.
- 카카오톡 안의 브라우저에서는 Google 로그인이 막혀 있어요. 구독(BCL)은 로그인 없이 돼요.

## 보안 메모

- `firebase-config.js`의 apiKey는 공개돼도 되는 값이에요. 데이터 보호는 `firestore.rules`가 맡아요. 단, Google Cloud 콘솔의 사용자 인증 정보에서 이 키에 Generative Language API(Gemini) 같은 Firebase 외 API를 허용하지 마세요.
- 구독 코드(BCL)를 아는 사람은 그 행사의 부스·작가 정보와 태그·부스 메모를 볼 수 있어요. 부스 메모에 개인적인 내용은 적지 마세요. 구매 리스트·지인은 공유되지 않아요.
- 편집 코드(BCE)와 편집 링크는 수정 권한이에요. 믿는 사람에게만 주고, 새어 나갔다면 설정 → 실시간 공유 → ‘코드 바꾸기’를 누르세요. 공동 편집자를 빼면 편집 코드도 자동으로 바뀌어요.
- 실시간 공유를 끝내면 공유 데이터 내용도 비워져서, 예전 코드로는 아무것도 볼 수 없어요.
- `firestore.rules`를 바꿨다면 Firebase 콘솔 → Firestore → 규칙 탭에 다시 붙여 넣고 게시해야 적용돼요.
- 받은 공유 코드·백업 파일·실시간 공유 데이터는 앱이 다시 검사해서 넣어요(링크는 http/https만, 내부 ID는 영문·숫자만, 글자 수·개수 제한, 압축 해제는 공유 데이터 3MB·백업 30MB까지).
